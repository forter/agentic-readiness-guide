# תוכן העניינים

## פתח דבר
- הקדמה - מדוע מוכנות לסוכנים היא ה"מוכנות למובייל" הבאה

## חלק א' - מסגרת מחזור החיים
- **פרק 1.** מבוא: מחזור החיים של הסוכן, חמשת המודולים, אבטחה מודעת-סוכנים, וכיצד לקרוא את המדריך

## חלק ב' - חמשת המודולים

### מודול 1 - להיות ניתנים לגילוי
- 1.1  פרסמו את קובצי הגילוי
- 1.2  הוסיפו קובצי סוכן ב-well-known ★
- 1.3  הציגו תוכן ללא JavaScript
- 1.4  בנו סמכות נושאית וכללי קידוד

### מודול 2 - להיות ניתנים להבנה
- 2.1  פרסמו נתונים מובנים מלאים ב-JSON-LD
- 2.2  הגישו llms.txt שימושי
- 2.3  תעדו עבור סוכנים
- 2.4  מצבו עצמכם תחרותית

### מודול 3 - להיות אמינים
- 3.1  ממשו OAuth ★
- 3.2  אמתו בוטים באופן קריפטוגרפי ★
- 3.3  הפכו את אישורי הגישה לשירות עצמי ★

### מודול 4 - להיות ניתנים לפעולה
- 4.1  ספקו מפרט OpenAPI ★
- 4.2  תקננו מגבלות קצב ושגיאות ★
- 4.3  הזרימו פעולות ארוכות-טווח ★
- 4.4  הפעילו שרת MCP ★
- 4.5  חשפו כלים עם WebMCP ★
- 4.6  הירשמו במרשמי סוכנים ★
- 4.7  הפיצו SDK ו-CLI ★
- 4.8  תמכו בפרוטוקולי תשלום לסוכנים ★
- 4.9  תמכו בפרוטוקולי מסחר אג'נטי ★
- 4.10  הפעילו נקודת קצה של NLWeb ★

### מודול 5 - להיות חווייתיים
- 5.1  קבלו אימות בפלטפורמות AI ★
- 5.2  הציגו UI עם MCP Apps ★
