# 模块5 - 可被体验
*“智能体闭合环路，把价值呈现回人的面前。”*

## 智能体的问题
> _“我完成了认证，调用了 API，拿到了结果。我该如何以完成用户意图的方式把它展示给用户？”_

模块1-4是基础设施。模块5是**产品** - 智能体驱动的流程在这里成为一种能与传统网页访问竞争的用户体验。一个把其余部分都做到位却跳过模块5的网站，等于建了一个没人看得见的漂亮 API。

## 体验的三个平面

1. **内联 UI。** MCP Apps 让你的工具在**聊天对话内部**渲染一个交互组件 - 支付选择器、确认框、对比视图。
2. **应用市场存在感。** ChatGPT GPT Store 与 **Custom GPTs**、Claude 集成、Gemini 扩展。已验证集成徽章可测量地提高推荐率。
3. **对话覆盖度。** 不会因为缺少定价或对比内容而走进死胡同的多轮流程。

## 关于体验安全的说明

内联 UI 渲染在一个与其他工具的组件共享的宿主环境中。像对待任何公开面一样对待你的组件包：签名、CSP 锁定、网络限定到你的源站。持续仿真（[5.4](./m5-4-end-to-end-flows.md)）能在宿主运行时漂移触达用户之前抓住它。
