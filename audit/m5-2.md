# m5-2 - MCP Apps

## Probe

```bash
# Re-use the discover/initialize result and era from m4-4 (run that probe first).
# As of MCP 2026-07-28 the Apps capability is a first-class extension advertised under
# `capabilities.extensions["io.modelcontextprotocol/ui"]`; older servers used
# `capabilities.experimental.apps`. Accept either.
jq -r '.result.capabilities.extensions["io.modelcontextprotocol/ui"]
       // .result.capabilities.experimental.apps
       // .result.capabilities.apps' /tmp/init.json 2>/dev/null
# Derive the era from m4-4's saved result rather than its stdout: a modern server/discover
# result carries `protocolVersions` (plural), a legacy initialize result `protocolVersion`.
if jq -e '.result.protocolVersions' /tmp/init.json >/dev/null 2>&1; then ERA=modern
elif jq -e '.result.protocolVersion' /tmp/init.json >/dev/null 2>&1; then ERA=legacy
else ERA=modern; fi
echo "era $ERA"
MODERN=2026-07-28
META="\"_meta\":{\"io.modelcontextprotocol/protocolVersion\":\"$MODERN\",\"io.modelcontextprotocol/clientCapabilities\":{\"extensions\":{\"io.modelcontextprotocol/ui\":{\"mimeTypes\":[\"text/html;profile=mcp-app\"]}}},\"io.modelcontextprotocol/clientInfo\":{\"name\":\"audit\",\"version\":\"1.0\"}}"

# List tools and look for _meta.ui.resourceUri. Declare the ui extension as a client capability -
# a 2026-07-28 server MUST NOT rely on a capability the client did not declare.
if [ "$ERA" = modern ]; then
  curl -fsS -X POST $ORIGIN/mcp \
    -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
    -H "MCP-Protocol-Version: $MODERN" -H 'Mcp-Method: tools/list' \
    --data "{\"jsonrpc\":\"2.0\",\"id\":2,\"method\":\"tools/list\",\"params\":{$META}}" \
    -o /tmp/uitools.raw
else
  curl -fsS -X POST $ORIGIN/mcp \
    -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
    --data '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}' \
    -o /tmp/uitools.raw
fi
sed -n 's/^data: //p' /tmp/uitools.raw > /tmp/tools.json 2>/dev/null; [ -s /tmp/tools.json ] || cp /tmp/uitools.raw /tmp/tools.json

jq -r '[.result.tools[]? | select(._meta.ui.resourceUri)] | length' /tmp/tools.json 2>/dev/null

# Pull one ui:// resource via resources/read if available
URI=$(jq -r 'first(.result.tools[]? | ._meta.ui.resourceUri // empty)' /tmp/tools.json 2>/dev/null)
if [ -n "$URI" ]; then
  if [ "$ERA" = modern ]; then
    curl -fsS -X POST $ORIGIN/mcp \
      -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
      -H "MCP-Protocol-Version: $MODERN" -H 'Mcp-Method: resources/read' \
      --data "{\"jsonrpc\":\"2.0\",\"id\":3,\"method\":\"resources/read\",\"params\":{\"uri\":\"$URI\",$META}}" \
      -o /tmp/ui.raw
  else
    curl -fsS -X POST $ORIGIN/mcp -H 'Content-Type: application/json' \
      --data "{\"jsonrpc\":\"2.0\",\"id\":3,\"method\":\"resources/read\",\"params\":{\"uri\":\"$URI\"}}" \
      -o /tmp/ui.raw
  fi
  sed -n 's/^data: //p' /tmp/ui.raw > /tmp/ui.json 2>/dev/null; [ -s /tmp/ui.json ] || cp /tmp/ui.raw /tmp/ui.json
fi
# MIME should be the MCP Apps profile, not bare text/html
jq -r '.result.contents[0].mimeType' /tmp/ui.json 2>/dev/null

# MCP Apps CSP is NOT arbitrary site CSP: the spec declares domain allowlists under _meta.ui.csp
# (connectDomains/resourceDomains/frameDomains/baseUriDomains) and the host enforces a
# default-src 'none' / object-src 'none' baseline. Check for those specifically.
jq -e '[.result.tools[]? | ._meta.ui.csp | select(.!=null)
        | (has("connectDomains") or has("resourceDomains") or has("frameDomains") or has("baseUriDomains"))] | any' \
  /tmp/tools.json >/dev/null 2>&1 && echo "ui.csp allowlist declared" || echo "ui.csp allowlist absent"
jq -r '.result.contents[0].text // ""' /tmp/ui.json 2>/dev/null \
  | grep -iqE "default-src 'none'|object-src 'none'|profile=mcp-app" && echo "mcp-app csp baseline" || echo "no mcp-app csp baseline"
```

## Rubric

| # | Sub-check | Pass when | Weight |
|---|-----------|-----------|--------|
| 1 | MCP server advertises the Apps capability | `capabilities.extensions["io.modelcontextprotocol/ui"]` present (MCP `2026-07-28`, where Apps is a first-class extension), **or** the older `capabilities.experimental.apps` / `capabilities.apps` on a legacy server | 1 |
| 2 | At least one tool with `_meta.ui.resourceUri` | Count ≥ 1 | 1 |
| 3 | `ui://` resource resolvable | `resources/read` returns content | 1 |
| 4 | CSP is MCP-Apps-scoped (not generic) | The tool/resource declares `_meta.ui.csp` domain allowlists (`connectDomains`/`resourceDomains`/`frameDomains`/`baseUriDomains`), **or** the bundle carries the MCP Apps baseline (`default-src 'none'` + `object-src 'none'`) / MIME `text/html;profile=mcp-app`. A bare site-wide `Content-Security-Policy` header that isn't one of these does **not** count | 1 |
| 5 | Component schema declared | The UI resource declares an `inputSchema` (or `propsSchema`) field in its `_meta` block - even before validating compatibility, the schema must be present and parseable as JSON Schema | 1 |

Status: **Pass** ≥ 4/5 · **Partial** 2-3/5 · **Fail** 0-1/5 · **N/A** for read-only / non-UI tools.

## Codebase hints

- **TypeScript**: [`@modelcontextprotocol/ext-apps`](https://www.npmjs.com/package/@modelcontextprotocol/ext-apps) (preview). Bundle each component as a signed `ui://` resource with locked CSP.
- **Bundling**: Vite/esbuild → static JS bundle, hosted alongside MCP server (`/mcp/ui/{tool}.js`).
- **Schema contract**: derive the component's props from the tool's `outputSchema` to avoid drift.
- **OpenAI Apps SDK** is the parallel non-MCP path; ship both if you target ChatGPT and Claude.
- **Security**: never inline user-supplied HTML - agents render the bundle in a sandboxed iframe with strict CSP.
- **View origin (sub-check 4)**: when the bundle is served from your own domain rather than inline, that origin's response CSP also has to permit the host sandboxes - `frame-ancestors` listing both `https://chatgpt.com` and `https://claude.ai`. A wildcard `default-src *` renders but reads as unscoped.
